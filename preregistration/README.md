# Study 1 pre-registration

`study1.md` will be written only after the pilot, final comprehension check, and
approved mechanical fixes. The design is not locked at this stage.

The final document must contain P1/P2/S1/S2 and estimands, study outcomes, model
IDs and observed versions, verified API settings and schemas, final prompt paths
and SHA-256 hashes with full text in an appendix, the main manifest path/hash and
seed, comprehension procedure/results, exclusion and deviation rules, and the
analysis paths/commit with an exact reproduction command.

The main manifest will be generated without executing it. After a local commit,
the tag will be `prereg-study1`. Pushing the commit and tag requires explicit
permission; the pre-registration is not timestamp-locked on GitHub until that
push succeeds. Study 2's protocol will follow in a separate addendum.
