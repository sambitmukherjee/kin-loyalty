# Study 1 experiment templates

This versioned directory is reserved for the three system/game paraphrases,
counterparty blocks, and comprehension-check text. Templates will be plain text.
The exact JSON instructions and protected prompt segments will be verified in
the prompt phase. No experiment prompt text has been implemented or approved yet.

The name pairs for paraphrases 2 and 3 in `configs/study1.yaml` are proposals.
The researcher must approve all prompt text before the pilot. Fully rendered
prompts for every decision × label × paraphrase for one model will be provided
for that review.

Local instructions for the coding agent belong in the separate, ignored
`codex_prompts/` directory. Do not copy them into this directory.
